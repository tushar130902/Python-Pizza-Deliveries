# 🍕 Python Pizza Deliveries

## Project Description
A beginner-friendly Python project that calculates the total pizza bill based on pizza size, pepperoni toppings, and extra cheese.

## Features
- Select pizza size (Small, Medium, Large).
- Add pepperoni topping.
- Add extra cheese.
- Automatically calculate the final bill.

## Technologies Used
- Python
- Conditional Statements (if, elif, else)
- Nested If Statements
- User Input
- Arithmetic Operators

## How to Run

1. Clone this repository.
2. Open the project in VS Code.
3. Run the following command:

```bash
python main.py
```
